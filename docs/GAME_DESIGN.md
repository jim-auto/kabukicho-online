# Kabukicho Online ゲーム設計

## コンセプト

Roblox夜街アクションMMO。日本のネオン街をモチーフにした巨大オンライン都市で、プレイヤーは客集め、評判稼ぎ、店ランキング、ライバル競争、街イベントへの対応を通じてNo.1ホストを目指す。

恋愛ゲームではなく、夜街サバイバル、ソーシャルPvP、Simulator/Tycoon的成長、カオスな都市アクションを組み合わせる。

## 体験の柱

- 一瞬で分かる: NPCに近づいて声をかけるとMoney/Reputationが増える
- すぐカオス: 突発イベント、物理オブジェクト、PvPプッシュで街が荒れる
- 配信映え: ネオン、看板、派手な通知、短いランキング競争
- 安全設計: 出会い、恋愛、性的コンテンツ、マッチング要素は扱わない
- 短時間ループ: 3〜5分で客集め、イベント、順位変動が発生する

## コアループ

1. ネオン街を移動する
2. NPCや街イベントに反応する
3. 客を獲得してMoney/Reputation/Charismaを得る
4. ライバルをプッシュして妨害または防衛する
5. カオスイベントで追加報酬を狙う
6. 店ランクと見た目を強化する
7. サーバー内ランキング上位を狙う

## MVPシステム

- PlayerDataService: leaderstatsとセッション値を管理
- EconomyService: 報酬、店ランク、ボーナス倍率を管理
- RankingService: サーバー内ランキングを返す
- NPCService: NPC生成、巡回、ProximityPromptインタラクション
- PvPService: 近距離プッシュ、軽いダメージ、クールダウン
- ChaosEventService: ランダム街イベント
- WorldBuilder: Placeに最低限の夜街を自動生成
- Client Main: HUD、モバイル操作、エモート、ランキング表示

## スケール方針

NPCはCollectionServiceタグと属性で扱い、将来的にスポーン地区、客タイプ、レア客、群衆密度を足せる構成にする。経済値はサーバーのみで更新し、クライアントはUI表示と入力送信に限定する。
