# 開発ロードマップ

## MVP優先順位

1. 歩く、走る、NPCに声をかける、報酬が入る
2. サーバー内ランキングが動く
3. ライバルをプッシュできる
4. カオスイベントで街が変化する
5. 店ランクが上がり、報酬倍率が増える
6. モバイルでも主要操作が押せる

## Phase 1: 遊べるプロトタイプ

- 自動生成ネオン街
- NPC 30体程度の巡回
- 客集めProximityPrompt
- Money/Reputation/Charisma
- 近距離プッシュPvP
- 3種類以上のカオスイベント
- HUDとランキング

## Phase 2: リテンション

- 店内Tycoonエリア
- 看板、照明、紙吹雪、登場演出の購入
- デイリー任務
- レア客とVIP客
- 3分ごとのミニシーズンランキング

## Phase 3: マルチプレイ強化

- 店チーム
- エリア制圧イベント
- NPC客の奪い合い
- PvPアイテム
- リプレイ映えするフィニッシュ演出

## Phase 4: 運用

- DataStore保存
- 不正入力の監視
- 報酬倍率のバランス調整
- イベントローテーション
- Roblox Analyticsで離脱ポイントを確認
